# Atividade Chart.js

Projeto desenvolvido com HTML, CSS, JavaScript e Chart.js para exibir dados de temperatura e umidade em dois tipos de gráfico.

## Gráficos desenvolvidos

- Gráfico de linha com temperatura e umidade por horário
- Gráfico de barras com médias mensais de temperatura e umidade

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Chart.js
